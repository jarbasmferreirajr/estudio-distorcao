# Estúdio Distorção

Site institucional de uma escola de música, com salas de ensaio e estúdio de gravação, em Blumenau (SC). A empresa é fictícia e foi criada para a atividade Projeto de Desenvolvimento Web da Especialização em Desenvolvimento Web do IFSULDEMINAS.

**Acesse:** https://jarbasmferreirajr.github.io/estudio-distorcao/

## Funcionalidades

- Menu fixo com navegação por seções, que fecha sozinho no celular após o clique
- Carrossel na página inicial com os três serviços
- Modal de serviços preenchido via JavaScript
- Loja com filtro por categoria, busca que ignora acentos e carrinho
- Formulários de contato e de aula experimental com validação, máscara de telefone e revalidação enquanto o usuário corrige
- Layout responsivo com Bootstrap 5

## Tecnologias

HTML5, CSS3, Bootstrap 5.3, JavaScript e Google Fonts (Bebas Neue e Inter).

## Como executar

Basta abrir o `index.html` no navegador. Não há dependências para instalar.

## Estrutura

```
index.html
css/style.css
js/main.js        menu, modal de serviços e formulários
js/catalogo.js    produtos, filtros, busca e carrinho
imagens/
Descrição Empresa Estúdio Distorção.pdf    descrição da empresa fictícia
```
